# Pocket Coast art studies

Serve the repository root over HTTP and open the linked HTML pages. These are
standalone studies and reusable exports. The production app uses its runtime
atlases under `assets/`; these source packs are not in its offline precache.

| Study | Entry point | Source and exports |
| --- | --- | --- |
| Field kit v1 | [Preview](pixel-lab/v1/index.html) | [Notes](pixel-lab/v1/README.md) |
| Style studies v2 | [Notes and boards](pixel-lab/v2/README.md) | [Pack](pixel-lab/v2/lacanau-style-studies-v2.zip) |
| Pocket Coast v3 | [Notes and boards](pixel-lab/v3-pocket-coast/README.md) | [Pack](pixel-lab/v3-pocket-coast/pocket-coast-handheld-v3.zip) |
| Complete v3 catalogue | [Assets](pixel-lab/v3-complete/README.md) | [Animations](pixel-lab/v3-complete/animations/README.md) |
| Seeded pool maps v4 | [Generator and exports](pixel-lab/v4-pool-maps/README.md) | [Layouts](pixel-lab/v4-pool-maps/exports/manifest.json) |
| Living world v5 | [Interactive garden](pixel-lab/v5-living-world/index.html) | [Notes](pixel-lab/v5-living-world/README.md) |
| Sound study | [Listen](pixel-lab/v5-living-world/sound-library.html) | [Scores, synthesis and downloads](pixel-lab/v5-living-world/audio/README.md) |
| Surface lab | [Interactive materials](surface-lab/index.html) | [Notes](surface-lab/README.md), [saved looks](surface-lab/presets/README.md) |
| Pool study | [A pool map on the living ground](surface-lab/pool.html) | [Notes](surface-lab/README.md#pool-study) |

The surface lab contains grass, sand, earth, gravel and water, regional grain
variation, weather response, colour grading, reflections and opt-in sound.
The pool study composes it under the real pool maps with the zone kit's trees
and sheds; wiring that composition into the production game remains a separate
development pass.
